# Contrôle des morceaux : Tubes francophones

Recherche Deezer du 2026-10-04. Pour chaque morceau : ouvrir le lien, écouter, vérifier que c'est
la bonne version (pas un remix, une reprise ni un karaoké), puis passer `verified` à `true` dans
`tubes-francophones.json`. Si une alternative est meilleure, la copier dans `found` avant de cocher.
Ensuite : `npm run build`, qui refuse tout morceau non vérifié.
