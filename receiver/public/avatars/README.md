# Avatars de la TV

Dessins des 24 avatars (`shared/avatars.ts`), un fichier par emoji, nommé d'après son point de code
(`1f98a.svg` pour 🦊). La TV les affiche en images : certaines TV (Philips) n'ont pas de police emoji
et n'affichaient qu'une pastille blanche.

Source : Noto Emoji de Google, dossier `svg/`, commit `41e31b110b4eb929dffb410264694a06205b7ad7`
(février 2024, avant le passage de la licence du dépôt à l'OFL), https://github.com/googlefonts/noto-emoji.
